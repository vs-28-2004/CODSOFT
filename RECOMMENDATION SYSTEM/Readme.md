


# Movie Recommendation System

## Overview

This project is a Movie Recommendation System developed using Python, Pandas, and Streamlit. The application recommends movies to users based on the movie they select. Recommendations are generated by comparing movie genres and considering movie ratings from the MovieLens dataset.

The goal of this project was to understand how recommendation systems work and to gain experience with data processing, filtering techniques, and building interactive web applications using Streamlit.

## Dataset

The project uses the MovieLens Small Dataset, which contains movie information and user ratings.

Files used:

* movies.csv
* ratings.csv

The dataset provides movie titles, genres, and ratings that are used to generate recommendations.

## Technologies Used

* Python
* Pandas
* Streamlit

## How the Project Works

1. The application loads movie and rating data from the MovieLens dataset.
2. The user selects a movie from the dropdown menu.
3. The system finds movies with similar genres.
4. Movies with higher ratings and a larger number of ratings are given higher priority.
5. The top recommended movies are displayed on the screen.

## Features

* Interactive user interface
* Movie selection from a dropdown menu
* Genre-based recommendations
* Rating-based ranking of recommendations
* Dataset statistics display
* Clean and responsive Streamlit layout

## Installation

Install the required libraries:

```bash
pip install streamlit pandas
```

## Running the Application

Open the project folder and run:

```bash
streamlit run streamlit_app.py
```

The application will start in your default web browser.
