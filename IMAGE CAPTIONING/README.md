# Image Captioning Application

## Overview

Image Captioning Application is an AI-powered web application that automatically generates descriptive captions for uploaded images.

Users can upload an image through a simple web interface and receive a meaningful text description generated by the AI model.

## Features

* Upload images from the browser
* Automatic image caption generation
* AI-powered image understanding
* Fast and user-friendly interface
* REST API integration between frontend and backend
